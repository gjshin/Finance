# GPCM Calculator

유사기업 배수(GPCM)와 WACC를 계산해 **엑셀로 뽑아주는** 프로그램. 앱이 두 개다.

| | **국내 상장사** | **해외 상장사** |
|---|---|---|
| 실행 | **`run_kr.bat`** | **`run_global.bat`** |
| 코드 | `gpcm_kr.py` | `GPCM.py` |
| 데이터 | DART 공시 재무제표 | Yahoo Finance |
| 인증키 | **필요** (DART, 무료) | **불필요** |
| 종목 지정 | 종목코드 6자리 (`005930`) | 야후 티커 (`7273.T`, `MG.TO`) |
| 실행 위치 | **국내에서만** (DART가 해외 접속 차단) | 어디서든 |

둘 다 계산에 쓴 중간값이 엑셀에 함께 들어간다. **조서에 넣기 전에 대사할 수 있다.**

---

# 설치 — 2단계 (공통)

**파이썬을 따로 설치할 필요가 없다.** 준비는 실행 파일이 알아서 한다.

1. 위쪽 초록색 **Code** → **Download ZIP** → 압축 해제
2. **`run_kr.bat`**(국내) 또는 **`run_global.bat`**(해외) **더블클릭**

검은 창이 뜨고 준비가 시작된다. **처음에는 3~5분 걸린다.** 창을 닫지 말 것.
준비가 끝나면 브라우저가 자동으로 열린다. 다음부터는 바로 뜬다.

**끄실 때는 검은 창을 그냥 닫으면 된다.**

## 다시 실행할 때

**같은 파일을 다시 더블클릭하면 된다.** 준비 과정은 건너뛰고 몇 초 만에 뜬다.
파이썬과 라이브러리는 처음 한 번만 받고, 그 뒤로는 `%LOCALAPPDATA%\uv` 에 보관된 것을 쓴다.

| 상황 | 어떻게 |
|---|---|
| 다시 쓰고 싶다 | `run_kr.bat` / `run_global.bat` 더블클릭 |
| 브라우저 탭만 실수로 닫았다 | 검은 창이 살아 있으면 <http://localhost:8501> 을 다시 열면 된다 |
| 완전히 끄고 싶다 | **검은 창을 닫는다.** 브라우저만 닫으면 프로그램은 계속 돌고 있다 |
| 매번 폴더 찾기 번거롭다 | `run_kr.bat` 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)** |

> **폴더를 옮기거나 지웠다가 다시 받아도** 준비 과정을 다시 겪지 않는다.
> 받아 둔 파이썬과 라이브러리는 이 폴더 밖에 있다.

> **폴더 위치** — OneDrive나 바탕화면 동기화 폴더 안에 두면 문제가 생길 수 있다.
> `C:\GPCM` 같은 단순한 경로를 권한다.

# 국내 상장사 — `run_kr.bat`

## DART 인증키 (처음 한 번, 무료)

1. <https://opendart.fss.or.kr> 접속 → 오픈API 이용 신청 → 이메일 인증
2. 발급된 키(영문·숫자 40자)를 복사해 둔다

**각자 본인 키를 발급받아 쓴다.** 하루 조회 한도가 키마다 주어져서, 한 키를 여럿이
나눠 쓰면 금방 한도에 걸린다.

> **국내에서 실행해야 한다.** DART가 해외 접속을 막는다. 회사 PC나 개인 PC에서는 문제없다.

## 입력

브라우저가 열리면 왼쪽에 입력칸이 나온다.

| | |
|---|---|
| **OpenDart API Key** | 발급받은 40자 키. 화면에 표시되지 않는다 |
| **분석 모드 선택** | `GPCM Valuation` 또는 `다기간 재무제표 요약` |

### 모드 ① GPCM Valuation — 배수와 WACC

| | |
|---|---|
| 분석 주기 | 분기별 / 연간 |
| 시작·종료 (연도·분기) | 아직 공시 안 된 분기를 고르면 가능한 최근 기간을 알려준다 |
| **종목코드** | 한 줄에 하나씩. 예: `005930` |
| Rf / MRP | 무위험이자율, 시장위험프리미엄 |
| 기업 규모 | Size premium 적용 구간 |
| Beta 종류 | WACC에 쓸 베타 (5Y Monthly / 2Y Weekly) |
| Kd / Target 법인세율 | 세전 타인자본비용, 목표 세율 |

**`Go,Go,Go 🚀`** → 계산이 끝나면 엑셀을 내려받는다.

**엑셀 시트**

| 시트 | 내용 |
|---|---|
| `GPCM` | 회사별 배수 한 줄씩. 메인 결과 |
| `Multiples_Trend` | 기간별 배수 추이 |
| `LTM_Calc` | LTM 환산 과정 |
| `PL_Data` / `BS_Full` | 손익·재무상태표 원본 |
| `Market_Cap` | 시가총액·주식수 |
| `Beta_Calculation` | 베타 산출 과정 |
| `WACC_Calculation` | 자본비용 계산 |

### 모드 ② 다기간 재무제표 요약

여러 회사의 과거 N년치 재무제표를 한 번에 받아 정리한다.

- **조회 기준** — `연간(사업보고서)` 또는 `분기 선택`
- 시작·종료 연도, 종목코드 입력 → **`재무제표 일괄 조회 🚀`**

엑셀에 `Summary` 시트와 **회사별 시트**가 만들어진다.

# Claude 데스크톱에서 GPCM 실행하기 — `install_mcp.ps1`

채팅으로 피어를 고른 뒤 종목코드를 복사해 앱을 따로 켜는 대신, **Claude 데스크톱
대화 안에서 GPCM을 바로 실행**할 수 있다. Streamlit 앱과 별개의 통로일 뿐,
앱은 그대로 쓸 수 있다.

## 등록 (처음 한 번)

이 폴더에서:

```
powershell -ExecutionPolicy Bypass -File .\install_mcp.ps1
```

- DART 인증키를 물어본다. **mydart를 이미 설치했다면 그 키를 자동으로 찾아 쓴다.**
- 끝나면 자체점검이 돌아 DART 연결까지 확인해준다 (첫 실행은 몇 분).
- Claude Desktop을 켜고 설정 → 개발자에 `gpcm`이 보이면 성공.

## 사용

대화에서:

```
run_gpcm으로 005930, 000660, 042700 돌려줘. 기간은 2025.4Q
```

- 실행은 백그라운드로 돌고, 진행·결과는 Claude가 `gpcm_status`로 확인해 알려준다.
- 결과 엑셀은 **문서\GPCM** 폴더에 저장된다. 시트 구성은 앱과 동일하다
  (GPCM·Data_Quality·WACC·Beta·BS_Full·PL_Data·Market_Cap·LTM_Calc…).
- **숫자를 쓰기 전에 Data_Quality 시트부터** — 앱과 같은 원칙이다.

## 폴더를 옮기면

등록된 경로가 어긋나므로 `install_mcp.ps1`을 새 위치에서 다시 실행한다.

# 해외 상장사 — `run_global.bat`

**인증키가 필요 없다.** Yahoo Finance에서 바로 받아온다.

## 티커 입력이 핵심이다

야후파이낸스 기준 티커를 **한 줄에 하나씩** 넣는다. 거래소마다 접미사가 다르다.

```
7273.T      ← 도쿄
MG.TO       ← 토론토
EZM.F       ← 프랑크푸르트
200880.KS   ← 코스피
PYT.VI      ← 빈
AAPL        ← 미국 (접미사 없음)
```

**확실하지 않으면 <https://finance.yahoo.com> 에서 회사를 검색해 나오는 티커를 그대로 쓴다.**
티커가 틀리면 그 회사만 빈 줄로 나온다.

## 입력

| | |
|---|---|
| **Analysis Mode** | `GPCM Valuation (Multi-Period)` 또는 `Historical FS Summary` |
| **분석 년수 (N개년)** | 1~10년 |
| **Base Year / Base Quarter** | 기준 시점 |
| **Tickers** | 위 형식으로 한 줄씩 |
| Rf / MRP / 기업 규모 / Beta 종류 / Kd / Target 법인세율 | 국내판과 같다 |

### Target 회사 직접 입력 (선택)

유사기업 배수를 **평가 대상 회사에 적용한 결과**까지 받고 싶을 때, 대상 회사의 숫자를
직접 넣는다. 상장사가 아니어도 된다.

```
Revenue (매출)          EBITDA              EBIT (영업이익)
Net Income (지배주주순이익)  Equity (자본총계)      IBD (이자부부채)
Cash (현금성자산)         NCI (비지배지분)       발행주식수
```

넣으면 엑셀에 **`Implied_Valuation`** 시트가 생긴다. 배수별 추정 기업가치와 주당가치다.
비워 두면 유사기업 배수만 나온다.

**`Go, Go, Go 🚀`** → 계산이 끝나면 엑셀을 내려받는다.

## 엑셀 시트

| 시트 | 내용 |
|---|---|
| `GPCM` | 유사기업별 배수. 메인 결과 |
| `Multiples_Trend` | 기간별 배수 추이 |
| `Implied_Valuation` | Target 숫자를 넣었을 때의 추정 가치 |
| `Historical_Summary` | 과거재무정보 요약 모드의 결과 |
| `Market_Cap` / `Price_History` | 시가총액, 주가 이력 |
| `Beta_Calculation` | 베타 산출 과정 |
| `WACC_Calculation` | 자본비용 계산 |
| **`Data_Quality`** | **어느 값을 못 받았는지. 결과가 이상하면 여기부터 본다** |

법인세율은 KPMG의 국가별 법인세율 표를 참조한다. 티커의 상장 국가로 자동 매칭된다.

## 기준일이 두 개다 — 헷갈리기 쉬운 곳

**입력한 Base Year/Quarter가 곧 손익 기준일이 아니다.**

| | 무엇 |
|---|---|
| **Base Date** | 입력한 기준일. **주가·시가총액**이 이 시점 기준이다 |
| **PL Date** | 실제로 쓴 **손익 기간의 끝**. 아래 이유로 Base Date와 다를 수 있다 |
| **BS Date** | 실제로 쓴 재무상태표 시점 |

손익 기준일이 달라지는 경우는 둘이다.

- **결산월이 기준일과 어긋날 때** — 3월 결산 회사에 6월을 기준일로 넣으면,
  그 시점 이전의 최신 회계연도(3월말)가 쓰인다. 기준일 이후 확정된 재무제표를 쓰면
  실제로는 알 수 없었던 정보를 쓰는 셈이 되기 때문이다
- **LTM일 때** — 최근 4개 분기 합계라, 끝점은 마지막 분기말이 된다

**어느 쪽이든 `PL Date` 열에 실제 시점이 찍힌다.** 대체가 일어나면 `Data_Quality`
시트에도 남는다. 배수를 조서에 옮기기 전에 이 열을 확인할 것.

# 결과 숫자에 대해

- 계산에 쓴 값들이 엑셀에 함께 들어간다. **조서에 넣기 전 확인할 것**
- 값이 비어 있으면 `0`이 아니라 **"해당 값을 받지 못했다"** 는 뜻이다
- 국내판은 DART 공시 재무제표를, 해외판은 Yahoo Finance 데이터를 그대로 읽는다.
  **Yahoo 데이터는 회사·거래소에 따라 빠지는 항목이 있다.** `Data_Quality` 시트로 확인한다

# 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `준비 도구(uv)를 설치하지 못했습니다` | 회사망 방화벽이 `astral.sh`를 막는 경우다. 전산팀 문의 또는 다른 네트워크에서 한 번 실행 |
| `앱을 실행하지 못했습니다` | 방화벽이 `pypi.org`를 막는 경우가 많다. 위와 같다 |
| **DART 서버에 접속할 수 없습니다** (국내판) | 방화벽이 `opendart.fss.or.kr`을 막고 있다. 전산팀에 허용 요청 |
| 특정 회사만 결과가 빈다 (해외판) | 티커가 틀렸거나 Yahoo에 그 항목이 없다. `Data_Quality` 시트 확인 |
| 결과가 통째로 빈다 | 그 기간 공시·데이터가 아직 없거나, 종목코드·티커 형식이 틀렸다 |
| 검은 창이 바로 닫힘 | 창에 뜬 메시지를 캡처해서 문의 |
| 느리다 | 회사 수 × 기간 수만큼 조회한다. 회사가 많으면 오래 걸린다 |

# 업데이트

새 ZIP을 받아 **폴더 전체를 교체**하면 된다. 준비 과정은 다시 겪지 않는다.

`requirements.txt`가 바뀐 경우에만 첫 실행에서 달라진 라이브러리를 받는다 (보통 1분 내외).

# 이 폴더의 파일들

| 파일 | 용도 |
|---|---|
| `run_kr.bat` | **국내 상장사 — 이것만 더블클릭** |
| `run_global.bat` | **해외 상장사 — 이것만 더블클릭** |
| `gpcm_kr.py` / `GPCM.py` | 각 앱 본체 |
| `requirements.txt` | 필요한 라이브러리 목록 — 실행 파일이 알아서 쓴다 |

| `gpcm_mcp.py` / `requirements-mcp.txt` | 데스크톱 연동 본체 — 직접 실행할 일 없음 |
| `test_gpcm_kr.py` 등 `test_*.py` | 개발자용 검증 코드 |

# 개발

```bash
uv run --no-project --with-requirements requirements.txt python -m streamlit run gpcm_kr.py
uv run --no-project --with-requirements requirements.txt python -m streamlit run GPCM.py
uv run --no-project --with-requirements requirements.txt --with pytest python -m pytest test_gpcm_kr.py
uv run --no-project --with-requirements requirements-mcp.txt python test_gpcm_mcp.py
```

`requirements.txt`는 **버전을 고정해 두었다.** 고정하지 않으면 재실행 때마다 최신 버전이
설치되어, 코드를 건드리지 않았는데 앱이 갑자기 깨진다.
