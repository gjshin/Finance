# GPCM Calculator

유사기업 배수(GPCM)와 WACC을 계산해 **엑셀 조서로 뽑아주는** 프로그램.

- 비교기업 종목코드를 넣으면 재무제표·주가·주식수를 **DART와 거래소 자료에서 받아와** 배수(EV/EBIT, PER, PBR, PSR)와 베타·WACC을 계산한다.
- 계산에 쓴 원자료와 중간 계산이 엑셀 수식으로 함께 남는다. **조서에 옮기기 전에 대사할 수 있다.**
- 자동으로 메우거나 바꾼 값은 전부 `Data_Quality` 시트에 기록된다.

최신 버전: **0.9.0** (`manifest.json` 기준)

## 무엇을 쓸까

| | **국내 상장사 앱** | **해외 상장사 앱** | **Claude 데스크톱 확장** |
|---|---|---|---|
| 이럴 때 | 국내 피어로 GPCM·WACC | 해외 피어(일본·미국·유럽 등) | Claude와 대화하며 피어를 고르고 바로 실행 |
| 실행 | **`run_kr.bat`** 더블클릭 | **`run_global.bat`** 더블클릭 | `gpcm-mcp.mcpb` 설치 후 채팅 |
| 데이터 | DART 공시 재무제표 + 거래소 주가 | Yahoo Finance | 국내 앱과 같다 |
| 인증키 | DART **필수**, ECOS 선택 | 불필요 | DART **필수**, ECOS 선택 |
| 종목 지정 | 종목코드 6자리 (`005930`) | 야후 티커 (`7273.T`, `MG.TO`) | 종목코드 6자리 |
| 실행 위치 | **국내에서만** (DART가 해외 접속 차단) | 어디서든 | 국내에서만 |
| 결과 | 브라우저에서 엑셀 내려받기 | 브라우저에서 엑셀 내려받기 | **문서\GPCM** 폴더에 저장 |

국내 앱과 Claude 확장은 계산 방식·엑셀 구성이 같다. 편한 쪽을 쓰면 된다.

# 5분 시작하기 (국내 앱)

**파이썬을 따로 설치할 필요가 없다.** 준비는 실행 파일이 알아서 한다.

## 1. 프로그램 받기

위쪽 초록색 **Code** → **Download ZIP** → 압축 해제.
`C:\GPCM` 같은 단순한 경로에 두는 것을 권한다. (OneDrive·바탕화면 동기화 폴더는 피한다)

## 2. 인증키 준비 (처음 한 번, 무료)

| 키 | 필요 여부 | 발급 | 쓰는 곳 |
|---|---|---|---|
| **OpenDART 인증키** | **필수** | <https://opendart.fss.or.kr> → 오픈API 이용 신청 → 이메일 인증 → 40자 키 | 재무제표·주식수·자기주식 |
| **한국은행 ECOS 인증키** | 선택 | <https://ecos.bok.or.kr> → 개발자센터 → 인증키 신청 | 기준일 **회사채** 금리, 국고채 20·30년물 |

- **각자 본인 키를 쓴다.** 하루 조회 한도가 키마다 있어 여럿이 나눠 쓰면 금방 막힌다.
- ECOS 키가 없어도 계산은 된다. 국고채(1·3·5·10년)는 키 없이 조회되고, 회사채 금리는 직접 넣으면 된다.

## 3. `run_kr.bat` 더블클릭

검은 창이 뜨고 준비가 시작된다. **처음에는 3~5분 걸린다.** 창을 닫지 말 것.
`WARNING` 문구가 보여도 정상이다. 준비가 끝나면 브라우저가 자동으로 열린다.

## 4. 첫 실행

1. 왼쪽 사이드바 맨 위 **OpenDart API Key** 칸에 키 붙여넣기 (ECOS 키는 바로 아래 칸)
2. **Target Companies** 에서 업종을 골라 비교기업을 체크하거나, `종목코드 직접 입력`으로 한 줄에 하나씩 입력
   — **피평가회사를 맨 첫 줄에** 넣는다 (법인세율 자동 산출 기준이 첫 번째 회사다)
3. **`Go,Go,Go 🚀`** 클릭 → 끝나면 엑셀 내려받기 버튼이 나온다
4. 엑셀을 열어 **`Data_Quality` 시트부터** 본다 (두 번째 시트에 있다)

## 끄기·다시 켜기·업데이트

| 상황 | 어떻게 |
|---|---|
| 끄고 싶다 | **검은 창을 닫는다.** 브라우저만 닫으면 프로그램은 계속 돈다 |
| 다시 쓰고 싶다 | 같은 `run_kr.bat` 더블클릭 — 준비 과정 없이 몇 초 만에 뜬다 |
| 브라우저 탭만 닫았다 | 검은 창이 살아 있으면 <http://localhost:8501> 을 다시 연다 |
| 매번 폴더 찾기 번거롭다 | `run_kr.bat` 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)** |
| **최신판으로 올리고 싶다** | **ZIP을 새로 받아 폴더 전체를 교체**한다. 준비 과정은 다시 겪지 않는다 |

`requirements.txt`가 바뀐 판이면 첫 실행에서 달라진 것만 받는다 (보통 1분 내외).

# 결과 엑셀 (국내 앱·Claude 확장 공통)

> **숫자를 조서에 옮기기 전에 `Data_Quality`부터 본다.**
> 자동 수집의 한계, 대체한 값, 평균에서 빠진 회사가 모두 여기에 있다.
> `ERROR` = 그 값을 쓰면 안 됨 / `WARN` = 값은 나왔으나 왜곡 가능 / `INFO` = 참고.

시트는 아래 순서로 만들어진다.

| 시트 | 내용 |
|---|---|
| `GPCM` | **메인 결과.** 회사별 한 줄 — EV 구성, LTM 손익, 시가총액, 배수, 베타, 세율, 부채비율, 무차입베타 |
| **`Data_Quality`** | **확인 필요 항목** (주황색 탭). 등급·종목·항목·내용 |
| `Peer_Selection` | 업종에서 고른 경우에만. 그때 떠 있던 후보 전체와 선택 표시(●) |
| `BS_Full` | 재무상태표 전체 계정과 EV 구성요소 태그(IBD·Cash·NOA·NCI 등) |
| `WACC_Calculation` | Rf·MRP·SRP·베타·Kd·세율·목표자본구조 → WACC. 엑셀 수식으로 계산되고 Notes에 방법론·출처가 적힌다 |
| `Beta_Calculation` | 베타 산출 과정 (엑셀 수식) |
| `PL_Data` | 손익 원자료 — 매출·영업이익·순이익·세전이익 |
| `Market_Cap` | 주가·주식수·시가총액과 **주식수의 근거** (아래 설명) |
| `LTM_Calc` | 기간별 LTM 환산 과정 (`PL_Data`를 수식으로 끌어온다) |
| `Multiples_Trend` | 기간별 배수 추이 |
| `Price_Daily` | 일별 종가. 회사마다 따로 된 [Date · 종가] 표, 마지막에 시장지수. 베타에 쓴 것과 같은 자료다. 그 종목이 실제 거래된 날만 담겨 회사마다 행 수가 다르다 (`일별 주가 시트`가 off면 없다) |

**감가상각비는 DART에서 자동으로 받지 못한다.** EV/EBITDA가 필요하면 `GPCM` 시트 `D&A` 칸에 직접 넣는다.

# 숫자 산출 기준

## 기준일

- **평가기준일 = 종료 기간의 분기말.** 주가·시가총액·베타·금리가 모두 이 날짜 기준이다.
- 기준일이 주말·휴장일이면 직전 거래일 종가를 쓴다.
- 기준일 이후의 주가·자료는 쓰지 않는다.

## 시가총액 — 유통주식수 우선순위 (0.9.0)

시가총액 = 기준일 보통주 종가 × 기준일 유통주식수. 유통주식수는 아래 순서로 정한다.

| 순위 | 상황 | 쓰는 주식수 | `Shares_Check` | Data_Quality |
|---|---|---|---|---|
| 1 | 기준일이 결산일인 DART 보고서가 있다 | DART 유통주식수(발행 − 자기주식). 기준일 KRX 상장주식수와 **대사**한다 | `발행=상장 일치` 또는 `발행−상장 ±N` | 다르면 WARN (전환 후 미상장 신주 등) |
| 2 | 보고서 **제출 전**이다 | **기준일 KRX 상장주식수 − 직전 보고서 자기주식** | `상장−자기주식` | 남는다. 그 사이 자기주식 취득·처분·소각 공시가 있으면 WARN |
| 3 | 기준일 명단 사본이 없다 (**2026-03-08 이전** 기준일) | 직전 보고서 유통주식수 그대로 | `직전 보고서` | WARN — 그 사이 증자·전환은 반영 안 됨 |
| 4 | DART를 못 받았다 | KRX 상장주식수 (자기주식 미차감) | `자기주식 미차감` | WARN |

- KRX 명단 사본은 거래소 상장종목 명단의 일자별 사본이다 (FinanceDataReader가 매일 보관하는 파일). 사본은 **2026-03-08부터** 있다.
- 2026년 1분기 이전 기준일이면 3순위로 내려간다. 이때는 `Data_Quality`를 보고 그 사이 주식수 변동을 공시로 확인한다.

## 우선주

- **상장 우선주**(종목명이 `우`·`우B`·`2우B` 등으로 끝나는 종목)가 있으면 **기준일 종가 × 우선주 유통주식수**(시가)로 자기자본가치에 더한다. `Market_Cap` N~R열에 근거가 있다.
- 상장 우선주를 기준일 당시 종목 명단에서 찾는다. 그 명단이 없으면 오늘 명단으로 찾고 WARN을 남긴다.
- 상장 우선주가 없으면 재무상태표 우선주자본금(액면)을 쓴다.
- `GPCM` 시트 `우선주(시가·장부)` 열은 시가 우선, 없으면 장부다.

## EV 구성

```
EV       = 시가총액 + 우선주 + IBD − Cash + NCI − NOA
Net Debt = IBD − Cash − NOA
```

- 재무제표는 **연결 우선, 없으면 별도**.
- CB·EB·BW 등 메자닌은 `IBD(Option)`, 투자자산·관계기업 등은 `NOA(Option)`으로 태그되어 기본적으로 EV에서 빠진다. 포함하려면 `BS_Full` 태그를 바꾼다.
- 비지배지분(NCI)은 계정명이 아니라 XBRL 코드로 찾는다.

## LTM

```
LTM = 당기 누적 + 직전 연간 − 전기 동분기 누적   (4Q는 연간 그대로)
```

`LTM_Calc` 시트에 회사·기간·계정별로 A·B·C가 수식으로 남는다.

## 베타

| | 5년 월간 (5Y Monthly) | 2년 주간 (2Y Weekly) |
|---|---|---|
| 관측치 | 수익률 **60개** | 수익률 **104개** (105주) |
| 창 | 기준일까지 5년 | 기준일(주말·휴장이면 직전 지수 거래일)이 속한 주까지 105주. 각 주 마지막 공통 거래일 종가 |
| 거래정지 | 관측치가 모자라면 WARN, 값은 그대로 쓴다 | 같다. 정지 구간을 창을 늘려 메우지 않는다 |

- **기준지수**: 기본 **코스피 일괄(^KS11)**. 피어 무차입베타를 평균해 하나의 WACC을 만들므로 모든 β가 같은 지수 기준이어야 하고, MRP도 시장 전체 기준 추정치이기 때문이다. `소속시장`을 고르면 코스닥 종목은 ^KQ11 기준이 되고, 두 시장이 섞이면 Data_Quality에 경고가 남는다.
- 수익률은 배당 미반영 가격수익률 (종목·지수 동일).
- **조정베타** = 2/3 × Raw + 1/3 × 1 (무차입 계산 전에 적용)
- **무차입베타** = 조정베타 / (1 + (1 − 세율) × D/E), D/E = IBD / (시가총액 + 우선주 + NCI)
- **평균 대상**: 조정베타가 0 초과인 회사 (`GPCM` 시트 Mean 행과 같은 모집단). 빠지는 회사는 Data_Quality에 남는다.
- **결정계수(R²) 0.1 미만**이면 Data_Quality에 INFO로 남는다. 배제하지 않는다 — 판단 재료다.
- Raw 베타가 ±3을 넘으면 WARN. 버리지 않는다.

## WACC

```
Ke   = Rf + 재부채베타 × MRP + Size Premium
WACC = Ke × E/V + Kd × (1 − 세율) × D/V
```

| 항목 | 출처 |
|---|---|
| **Rf** | 기준일 **국고채** 금리. 기본 5년물, 만기는 고른다. 키 없이 받아오고(1·3·5·10년), 안 되면 ECOS |
| **Kd** | 기준일 **회사채 3년** 금리 (AA- 또는 BBB-). ECOS 인증키 필요. 없으면 직접 입력 |
| **MRP** | 한국공인회계사회 「한국의 시장위험 프리미엄 가이던스」(2026.06.05) 7~9% |
| **Size Premium** | 한국공인회계사회 「기업규모위험 프리미엄 연구결과」(2026.06.05). 3분위: 2,583억 이하 4.02% / 2,585~8,671억 1.19% / 8,679억 초과 −0.45%. 5분위 표는 앱 참고표에 있다 |
| **목표자본구조** | 피어 평균 D/V |
| **법인세율** | 아래 |

조회한 금리와 출처, MRP·SRP 판(版)은 `WACC_Calculation` Notes에 남는다.

## 법인세율

한국 법인세 **한계세율** (지방소득세 포함). 세전이익(LTM)을 사업연도 세율표에 넣어 정한다.

| 과세표준 구간 | FY2023~2025 | FY2026~ |
|---|---|---|
| 2억 이하 | 9.9% | 11.0% |
| 2억~200억 | 20.9% | 22.0% |
| 200억~3,000억 | 23.1% | 24.2% |
| 3,000억 초과 | 26.4% | 27.5% |

- **피평가회사(타겟)**: `법인세율 자동`을 켜면 목록 첫 번째 회사의 세전이익으로 정한다. 적용된 세율과 근거가 화면과 Data_Quality에 남는다.
- **피어(무차입베타 계산용)**: 각 회사 세전이익으로 정한다.
- **세전이익이 0 이하(결손)**인 회사는 한계세율 개념이 성립하지 않아 **2구간 세율**(FY2026~ 22.0%, FY2023~2025 20.9%)을 쓰고 Data_Quality에 경고한다. 엑셀 수식도 같은 규칙이다.

# 해외 상장사 — `run_global.bat`

**인증키가 필요 없다.** Yahoo Finance에서 받아온다. 해외에서도 된다.
설치·실행·끄기는 국내 앱과 같다 (`run_global.bat` 더블클릭).

## 티커 입력이 핵심이다

야후파이낸스 기준 티커를 **한 줄에 하나씩** 넣는다. 거래소마다 접미사가 다르다.

```
7273.T      ← 도쿄
MG.TO       ← 토론토
EZM.F       ← 프랑크푸르트
200880.KS   ← 코스피
038110.KQ   ← 코스닥
PYT.VI      ← 빈
AAPL        ← 미국 (접미사 없음)
```

**확실하지 않으면 <https://finance.yahoo.com> 에서 회사를 검색해 나오는 티커를 그대로 쓴다.**
티커가 틀리면 그 회사만 빈 줄로 나온다.

## 입력

| 항목 | 설명 |
|---|---|
| **Analysis Mode** | `GPCM Valuation (Multi-Period)` 또는 `Historical FS Summary (과거재무정보 요약)` |
| **분석 년수 (N개년)** | 1~10년 |
| **Base Year (Y) / Base Quarter (Q)** | 기준 시점 |
| **Tickers** | 위 형식으로 한 줄씩 |
| Rf / MRP / 기업 규모 선택 | 국내판과 같다 (한공회 2026.06.05 판) |
| 일별 주가 시트 | `Price_History` 시트 구간 (기본 5Y, off 가능) |
| 베타 기준지수 (한국 종목) | `.KS`·`.KQ` 종목에만 적용. 기본 코스피 일괄 |
| WACC 계산에 사용할 Beta / Kd / Target 법인세율 | 국내판과 같다. 법인세율은 직접 입력 |
| **이상치 처리 방식** | `사용 안 함` / `IQR 방식 (권장)` / `백분위 방식`. WACC용 피어 평균에 적용되고, 제외된 피어는 Data_Quality에 남는다 |

### Target 재무수치 (선택)

유사기업 배수를 **평가 대상 회사에 적용한 결과**까지 받고 싶을 때, 대상 회사의 숫자를 직접 넣는다. 상장사가 아니어도 된다.

```
Revenue (매출)               EBITDA                 EBIT (영업이익)
Net Income (지배주주순이익)    Equity (자본총계)        IBD (이자부부채)
Cash (현금성자산)             NCI (비지배지분)         발행주식수 (주)
```

넣으면 `Implied_Valuation` 시트에 미리 채워진다. 비워 두면 엑셀에서 직접 넣는다.

**`Go, Go, Go 🚀`** → 계산이 끝나면 엑셀을 내려받는다.

## 엑셀 시트

| 시트 | 내용 |
|---|---|
| `GPCM` | 유사기업별 배수. 메인 결과 |
| `Multiples_Trend` | 기간별 배수 추이 |
| `Implied_Valuation` | 배수를 Target 숫자에 적용한 추정 가치 |
| `BS_FULL (base)` / `BS_Full_Y-1` … | 재무상태표 (base = 기준 시점, Y-1 = 1년 전 …) |
| `PL_Data (base)` / `PL_Data_Y-1` … | 손익 |
| `Market_Cap` | 시가총액 |
| `Price_History` | 일별 주가. 회사마다 [Date · Abs · Rel] 표, 그 종목이 거래된 날만 (수정주가 기준) |
| `Beta_Calculation` | 베타 산출 과정 |
| `WACC_Calculation` | 자본비용 계산 |
| **`Data_Quality`** | **못 받은 값·대체한 값·제외한 피어. 결과가 이상하면 여기부터** |
| `Historical_Summary` | 과거재무정보 요약 모드의 결과 |

피어 무차입베타에 쓰는 법인세율은 KPMG 국가별 법인세율 표에서 티커의 상장 국가로 자동 매칭된다.

## 기준일이 두 개다 — 헷갈리기 쉬운 곳

**입력한 Base Year/Quarter가 곧 손익 기준일이 아니다.**

| | 무엇 |
|---|---|
| **Base Date** | 입력한 기준일. **주가·시가총액**이 이 시점 기준이다 |
| **PL Date** | 실제로 쓴 **손익 기간의 끝**. Base Date와 다를 수 있다 |
| **BS Date** | 실제로 쓴 재무상태표 시점 |

- **결산월이 기준일과 어긋날 때** — 3월 결산 회사에 6월을 기준일로 넣으면 그 시점 이전의 최신 회계연도(3월말)를 쓴다. 기준일 이후 확정된 재무제표는 당시 알 수 없던 정보이기 때문이다.
- **LTM일 때** — 최근 4개 분기 합계라 끝점은 마지막 분기말이다.

어느 쪽이든 `PL Date` 열에 실제 시점이 찍히고, 대체가 일어나면 `Data_Quality`에도 남는다. **Yahoo 데이터는 회사·거래소에 따라 빠지는 항목이 있다.**

# 자주 묻는 문제

| 증상 | 원인과 해결 |
|---|---|
| **DART 서버에 접속할 수 없습니다** | 해외에서 실행 중이면 DART가 막는다 — 국내에서 실행한다. 국내인데 이러면 회사 방화벽이 `opendart.fss.or.kr`을 막는 것이니 전산팀에 허용 요청 |
| **"아직 공시되지 않은 기간이 포함되어 있습니다"** | 분기 종료 후 45일(사업보고서 90일)이 안 지났다. 화면의 "현재 조회 가능한 최신 공시" 이하로 종료 기간을 맞춘다 |
| 보고서 제출 전인 기준일로 돌리고 싶다 | 된다. 주식수는 기준일 KRX 상장주식수 − 직전 보고서 자기주식으로 계산되고 Data_Quality에 남는다. 손익·재무상태표는 공시된 기간까지만 받을 수 있다 |
| **최신 판이 도는지 모르겠다** | 앱: 사이드바 맨 위 `gpcm 0.9.0 · 폴더`. 확장: 채팅에서 `gpcm 점검해줘`(`gpcm_doctor`). 이 저장소 `manifest.json`의 버전과 비교한다 |
| 앱과 확장의 버전이 다르다 | 정상일 수 있다. 앱은 **내려받은 폴더가 곧 버전**(ZIP 재다운로드로 갱신), 확장은 **설치 시점 사본**(`.mcpb` 재설치로 갱신)이다 |
| 결과 엑셀이 어디 있나 | 앱: 브라우저 다운로드 폴더. 확장: **문서\GPCM** |
| 앱 폴더를 어디 둘까 | `C:\GPCM` 같은 단순한 경로. OneDrive·바탕화면 동기화 폴더는 피한다 |
| 금리 조회에서 회사채가 안 나온다 | ECOS 인증키가 비어 있다. 사이드바 상단 두 번째 칸에 넣는다 |
| 특정 회사 베타가 빠졌다 | Data_Quality의 Beta 항목을 본다 — 조정베타 0 이하, 관측치 부족 등 |
| `준비 도구(uv)를 설치하지 못했습니다` | 회사망 방화벽이 `astral.sh`를 막는다. 전산팀 문의 또는 다른 네트워크에서 한 번 실행 |
| `앱을 실행하지 못했습니다` | 방화벽이 `pypi.org`를 막는 경우가 많다. 위와 같다 |
| 특정 회사만 결과가 빈다 (해외판) | 티커가 틀렸거나 Yahoo에 그 항목이 없다. Data_Quality 확인 |
| 결과가 통째로 빈다 | 그 기간 공시·데이터가 아직 없거나, 종목코드·티커 형식이 틀렸다 |
| 검은 창이 바로 닫힘 | 창에 뜬 메시지를 캡처해서 문의 |
| 느리다 | 회사 수 × 기간 수만큼 조회한다. 회사가 많으면 오래 걸린다 |

값이 비어 있으면 `0`이 아니라 **"해당 값을 받지 못했다"**는 뜻이다.

# 개발

```bash
uv run --no-project --with-requirements requirements.txt python -m streamlit run gpcm_kr.py
uv run --no-project --with-requirements requirements.txt python -m streamlit run GPCM.py
uv run --no-project --with-requirements requirements.txt --with pytest python -m pytest test_gpcm_kr.py
uv run --no-project --with-requirements requirements-mcp.txt python test_gpcm_mcp.py
```

- `requirements.txt`는 **버전을 고정해 두었다.** 고정하지 않으면 재실행 때마다 최신 버전이 설치되어 코드를 건드리지 않았는데 앱이 깨진다.
- 버전은 `manifest.json` 한 곳에서 읽는다 (앱 사이드바와 `gpcm_doctor`가 같은 값을 보여준다).
- `.mcpb`는 이 폴더에서 `npx -y @anthropic-ai/mcpb pack . gpcm-mcp.mcpb` 로 다시 만든다.
