# GPCM Calculator

한국 상장사의 **유사기업 배수(GPCM)와 WACC를 계산해 엑셀로 뽑아주는** 프로그램.
DART 공시 재무제표를 직접 읽어 계산하므로, 숫자를 손으로 옮길 일이 없다.

- **배수** — EV/Sales, EV/EBITDA, EV/EBIT, PER 등을 LTM 기준으로
- **WACC** — Beta(5Y Monthly / 2Y Weekly) 산출부터 자본비용까지
- **다기간 재무제표** — 여러 회사의 N년치를 한 번에 표로

계산에 쓴 중간값이 엑셀에 전부 함께 들어간다. **조서에 넣기 전에 대사할 수 있다.**

---

# 설치 — 2단계

**파이썬을 따로 설치할 필요가 없다.** 준비는 `run_kr.bat`이 알아서 한다.

1. 위쪽 초록색 **Code** → **Download ZIP** → 압축 해제
2. **`run_kr.bat` 더블클릭**

검은 창이 뜨고 준비가 시작된다. **처음에는 3~5분 걸린다.** 창을 닫지 말 것.
준비가 끝나면 브라우저가 자동으로 열린다. 다음부터는 바로 뜬다.

> **폴더 위치** — OneDrive나 바탕화면 동기화 폴더 안에 두면 문제가 생길 수 있다.
> `C:\GPCM` 같은 단순한 경로를 권한다.

> **국내에서 실행해야 한다.** DART가 해외 접속을 막는다.
> 회사 PC나 개인 PC에서는 문제없다.

**끄실 때는 검은 창을 그냥 닫으면 된다.**

## DART 인증키 (처음 한 번, 무료)

1. <https://opendart.fss.or.kr> 접속 → 오픈API 이용 신청 → 이메일 인증
2. 발급된 키(영문·숫자 40자)를 복사해 둔다

**각자 본인 키를 발급받아 쓴다.** 하루 조회 한도가 키마다 주어져서, 한 키를 여럿이
나눠 쓰면 금방 한도에 걸린다.

---

# 쓰는 법

브라우저가 열리면 **왼쪽에 입력칸**, 오른쪽에 결과가 나온다.

## 공통 — 먼저 넣을 것

| | |
|---|---|
| **OpenDart API Key** | 발급받은 40자 키. 화면에 표시되지 않는다 |
| **분석 모드 선택** | `GPCM Valuation` 또는 `다기간 재무제표 요약` |

## 모드 ① GPCM Valuation — 배수와 WACC

**입력**

| | |
|---|---|
| 분석 주기 | 분기별 / 연간 |
| 시작·종료 (연도·분기) | 조회 구간. 아직 공시 안 된 분기를 고르면 가능한 최근 기간을 알려준다 |
| **종목코드** | 한 줄에 하나씩. 예: `005930` |
| Rf | 무위험이자율 (%) |
| MRP | 시장위험프리미엄 |
| 기업 규모 | Size premium 적용 구간 |
| Beta 종류 | WACC에 쓸 베타 (5Y Monthly / 2Y Weekly) |
| Kd | 세전 타인자본비용 |
| Target tax rate | 목표 법인세율 |

**`Go,Go,Go 🚀`** 를 누르면 계산이 시작되고, 끝나면 엑셀을 내려받을 수 있다.

**엑셀에 들어가는 시트**

| 시트 | 내용 |
|---|---|
| `GPCM` | 회사별 배수 한 줄씩. 메인 결과 |
| `Multiples_Trend` | 기간별 배수 추이 |
| `LTM_Calc` | LTM 환산 과정 |
| `PL_Data` | 손익 원본 |
| `BS_Full` | 재무상태표 원본 |
| `Market_Cap` | 시가총액·주식수 |
| `Beta_Calculation` | 베타 산출 과정 |
| `WACC_Calculation` | 자본비용 계산 |

## 모드 ② 다기간 재무제표 요약

여러 회사의 과거 N년치 재무제표를 한 번에 받아 정리한다.

- **조회 기준** — `연간(사업보고서)` 또는 `분기 선택`
- **시작·종료 연도**, **종목코드** 입력 → **`재무제표 일괄 조회 🚀`**

엑셀에 `Summary` 시트와 **회사별 시트**가 각각 만들어진다.

---

# 결과 숫자에 대해

- 배수와 WACC는 **DART 공시 재무제표를 그대로 읽어** 계산한다
- 계산에 쓴 값들이 엑셀에 함께 들어간다. **조서에 넣기 전 확인할 것**
- 값이 비어 있으면 `0`이 아니라 **"해당 계정을 찾지 못했다"** 는 뜻이다
- 아직 공시되지 않은 분기를 고르면 조회 가능한 최근 기간을 알려준다

---

# 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `준비 도구(uv)를 설치하지 못했습니다` | 회사망 방화벽이 `astral.sh`를 막는 경우다. 전산팀 문의 또는 다른 네트워크에서 한 번 실행 |
| `앱을 실행하지 못했습니다` | 방화벽이 `pypi.org`를 막는 경우가 많다. 위와 같다 |
| **DART 서버에 접속할 수 없습니다** | 방화벽이 `opendart.fss.or.kr`을 막고 있다. 전산팀에 허용 요청 |
| 결과가 비어 있다 | 그 기간 공시가 아직 없거나, 종목코드가 틀렸을 수 있다 |
| 검은 창이 바로 닫힘 | 창에 뜬 메시지를 캡처해서 문의 |
| 느리다 | 회사 수 × 기간 수만큼 DART를 조회한다. 회사가 많으면 오래 걸린다 |

# 업데이트

새 ZIP을 받아 **폴더 전체를 교체**하면 된다.
준비 과정은 다시 겪지 않는다 — 받아 둔 파이썬과 라이브러리는 폴더 밖에 보관된다.

---

# 이 폴더의 파일들

| 파일 | 용도 |
|---|---|
| `run_kr.bat` | **이것만 더블클릭하면 된다** |
| `gpcm_kr.py` | 국내 상장사용 앱 본체 |
| `GPCM.py` | 해외 상장사용 (별도 앱) |
| `requirements.txt` | 필요한 라이브러리 목록 — `run_kr.bat`이 알아서 쓴다 |
| `test_gpcm_kr.py` | 개발자용 검증 코드 |

---

# 개발

```bash
uv run --no-project --with-requirements requirements.txt python -m streamlit run gpcm_kr.py
uv run --no-project --with-requirements requirements.txt --with pytest python -m pytest test_gpcm_kr.py
```

`requirements.txt`는 **버전을 고정해 두었다.** 고정하지 않으면 재실행 때마다 최신 버전이
설치되어, 코드를 건드리지 않았는데 앱이 갑자기 깨진다.
